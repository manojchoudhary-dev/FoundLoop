# Campus Lost & Found

A campus lost-and-found notice board for IIIT Bhopal — FoCP (CSE-1003) project.

Students post lost or found items with a photo, place, date, category, description and contact. The board supports keyword search with possible-match suggestions, and items can be marked Reunited.

- Live site: deployed from this repo (Vercel)
- Stack: single-page web app; Firebase (Firestore) backend for shared, persistent listings
